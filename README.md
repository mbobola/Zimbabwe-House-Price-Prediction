# Zimbabwe House Price Prediction

This project collects Zimbabwean house and townhouse listings, explores and cleans the data, and compares a Ridge regression baseline with a multimodal image/text model. The checked-in dataset and photos let you run the analysis without scraping again.

## Repository contents

- `data/houses.csv` — listing snapshot, including source fields and photo paths.
- `data_dictionary.csv` — field descriptions and examples.
- `images/` — downloaded listing photos. Each filename starts with its `listing_id`, followed by the source photo ID (for example, `259991_<photo-id>.webp`).
- `src/scrape_listings.py` — optional incremental collection script.
- `notebooks/01_clean_explore.ipynb` — deduplication, USD target preparation, EDA, and exports.
- `src/train_models.py` and `notebooks/02_fit_models.ipynb` — model fitting and held-out evaluation.
- `reports/` — generated EDA/model outputs and the [project report](reports/project_report.md).
- `models/` — trained model artifacts generated by the model notebook.

The source `currency` field is blank for some rows. For this project, all listing prices are assumed to be USD, including rows with blank currency metadata; the cleaning notebook records the normalized value in its cleaned export. Revisit this assumption if the source or collection scope changes.

## Set up on Windows

Python 3.12 is used for this environment. In PowerShell, create the virtual environment and install dependencies:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m ipykernel install --user --name zimbabwe-house-price-prediction --display-name "Python (.venv: Zimbabwe House)"
```

In VS Code, open the repository folder and select **Python (.venv: Zimbabwe House)** as the kernel for both notebooks.

## Run the analysis

1. Run all cells in `notebooks/01_clean_explore.ipynb`. It creates cleaned listing data and EDA tables/figures under `reports/eda/`.
2. Run all cells in `notebooks/02_fit_models.ipynb`. It fits the Ridge and multimodal models, evaluates them on a held-out test set, and writes model files under `models/` plus metrics, predictions, and residual diagnostics under `reports/modeling/`.

The model notebook uses pretrained ResNet18 weights. The first run downloads those weights if they are not already cached, so an internet connection is needed.

## Optional data collection

The scraper uses the site's sitemap by default, checks `robots.txt`, enforces a minimum one-second request delay (two seconds by default), skips listing IDs already in `data/houses.csv`, and saves photos using the `listing_id` filename prefix. Check the source site's terms and robots policy before collecting. To try a small incremental collection:

```powershell
.\.venv\Scripts\python.exe src\scrape_listings.py --max-listings 25
```

Omit `--max-listings` to collect all new permitted listings. Collection requires network access and appends new rows to the local CSV.
